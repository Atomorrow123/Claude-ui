# 审美方向手册

选一个方向，然后**坚定地执行到底**。混搭两个以上方向几乎总是失败。
每个方向给出：适用场景 · 字体 · 配色 · 形状 · 深度 · 动效 · 签名细节 · 禁忌。

---

## A. Claude 原生（Warm Editorial Minimal）· 默认推荐

> 像一本印刷精良的书：温暖、安静、聪明，不抢内容的风头。

- **适用**：AI 产品、知识/阅读类、写作工具、个人站点、文档站、高端 SaaS
- **字体**：标题用衬线（Source Serif 4 / Newsreader / Fraunces，中文 Noto Serif SC）；正文无衬线（Inter / Geist / 苹方）；代码 Geist Mono
- **配色**：
  - 画布 `#faf9f5`（米白）· 表面 `#ffffff` · 下沉 `#f0eee6`
  - 文字 `#141413` / 次要 `#5e5d59` / 三级 `#87867f`
  - 强调 赤陶 `#c96442`（hover `#b4553a`）· 浅底 `#f5e6dd`
  - 边框 `rgba(31,30,29,0.10)`
  - 暗色：画布 `#1f1e1d` · 表面 `#262624` · 文字 `#ececea` · 强调 `#d97757`
- **形状**：圆角 8–12px，按钮 8px，输入框 8px，大卡片 16px
- **深度**：以 1px 低对比边框为主，阴影极轻（几乎看不见），弹窗才用明显阴影
- **动效**：克制，200ms ease-out，仅淡入与轻微位移（4–8px）
- **签名细节**：衬线大标题 × 无衬线正文的对比；赤陶色只出现在主按钮/链接/焦点；大量米白留白；偶尔的手绘感插画或细线图形
- **禁忌**：渐变、霓虹、毛玻璃、高饱和多色

## B. 编辑排版（Editorial / Magazine）

> 版式即设计。字体做主角，图片做配角。

- **适用**：内容品牌、媒体、作品集、长文落地页、活动页
- **字体**：高对比展示衬线（Instrument Serif / Fraunces Display / Playfair）做超大标题（64–120px），正文用易读衬线或人文无衬线
- **配色**：黑白为主 + 一个大胆点色（正红 `#e63b2e`、钴蓝 `#2a4bd7` 或柠檬黄 `#f2d43d`）
- **布局**：不对称网格、跨栏大图、首字下沉、引文放大、细线分隔（1px hairline）、页眉页脚信息栏
- **形状**：圆角 0–2px，硬朗
- **深度**：无阴影，纯平面 + 分隔线
- **签名细节**：超大字号对比（标题 : 正文 ≥ 6 : 1）；栏目编号 "01 / 02"；小号全大写宽字距标签
- **禁忌**：卡片堆砌、圆润按钮、图标卡片

---

## C. 瑞士极简（Swiss / International）

> 网格、对齐、无衬线，一切服从秩序。

- **适用**：工具类、开发者产品、设计机构、B 端后台
- **字体**：单一无衬线家族（Geist / Inter / Helvetica Now / Neue Haas），靠字重与字号做全部层级
- **配色**：纯中性灰阶（冷灰）+ 一个功能色（蓝 `#0a6cff` 或 黑 本身作为强调）
- **布局**：严格 12 栏，强左对齐，大量负空间，信息密度可高
- **形状**：圆角 4–6px
- **深度**：边框分隔，几乎无阴影
- **动效**：极快 120–150ms，几乎无感
- **签名细节**：完美对齐；等宽数字；超细分隔线；黑色实心主按钮
- **禁忌**：装饰性插画、衬线、渐变

---

## D. 暗色精密（Dark Precision / Linear-like）

> 精密仪器般的暗色界面，细节在光影里。

- **适用**：开发者工具、生产力工具、数据产品、AI 基础设施
- **字体**：Geist / Inter（字距 -0.01em），等宽 Geist Mono 用于数据/快捷键
- **配色**：
  - 背景 `#0b0b0c` → 表面 `#131315` → 抬升 `#1a1a1d`
  - 文字 `#ededef` / 次要 `#8a8f98` / 三级 `#5c6068`
  - 强调 一个克制的冷色（靛 `#7c84ff` 或 青 `#3ecfb4`），用量极少
  - 边框 `rgba(255,255,255,0.08)`
- **形状**：圆角 6–10px
- **深度**：表面明度分层 + 顶部 1px 内高光 `inset 0 1px 0 rgba(255,255,255,0.05)`；可用极弱的径向光晕做 Hero 背景
- **动效**：快速、精确，150–200ms；命令面板、快捷键提示 `⌘K`
- **签名细节**：键盘快捷键徽标；细边框 + 内高光；单色图标；微妙的网格/噪点背景
- **禁忌**：彩虹渐变、大面积强调色、纯黑 `#000` 背景配纯白文字

---

## E. 柔和亲和（Soft & Friendly）

> 温和、圆润、让人放松，但依然克制。

- **适用**：C 端消费应用、教育、健康、儿童、社区
- **字体**：圆润几何无衬线（Nunito / Figtree / Manrope / DM Sans，中文 HarmonyOS Sans / 苹方）
- **配色**：柔和低饱和主色（鼠尾草绿 `#7a9e7e`、雾蓝 `#7d9cc4`、杏 `#f0b48a`）+ 暖白背景 `#fbfaf7`；可有 2–3 个辅助柔色，但需统一明度
- **形状**：圆角 14–24px，按钮可全圆角
- **深度**：柔和大扩散阴影（低不透明度、带主色色相）
- **动效**：稍有弹性 `cubic-bezier(0.34, 1.3, 0.64, 1)`，但仅用于小元素（勾选、点赞）
- **签名细节**：友好插画；大圆角容器；圆形头像组；温暖的口语化文案
- **禁忌**：高饱和撞色、过多弹跳动效、幼稚化

---

## F. 新粗野主义（Neo-Brutalism）

> 有意的"粗糙"，个性压倒精致。

- **适用**：创意工具、年轻品牌、独立产品、活动页
- **字体**：粗重怪诞无衬线（Space Grotesk / Archivo Black / Clash Display）+ 等宽
- **配色**：米白或亮色背景 + 纯黑描边 + 2–3 个高饱和平涂色（`#ffde59` / `#ff6b6b` / `#4ecdc4`）
- **形状**：圆角 0 或 8px，**2–3px 纯黑边框**
- **深度**：硬阴影 `4px 4px 0 #000`，按下时位移归零
- **动效**：直接、干脆，hover 时阴影偏移变化
- **签名细节**：粗黑描边 + 硬投影；旋转的贴纸元素；超大粗体
- **禁忌**：柔和阴影、渐变、细字重——要么全做，要么别做

## 如何选择

| 如果产品是… | 首选 | 备选 |
|---|---|---|
| AI / 知识 / 写作 | A Claude 原生 | B 编辑 |
| 开发者工具 / 效率工具 | D 暗色精密 | C 瑞士 |
| B 端后台 / 数据密集 | C 瑞士 | A Claude 原生 |
| 内容品牌 / 作品集 | B 编辑 | A Claude 原生 |
| C 端消费 / 健康 / 教育 | E 柔和 | A Claude 原生 |
| 创意 / 年轻 / 活动 | F 新粗野 | B 编辑 |

用户没有明确偏好时，默认 **A · Claude 原生**。
